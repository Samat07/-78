# Малэсеп

Кыргыз тилиндеги мал чарба эсеби. Интерфейс интернет жокто да мурда кирген түзмөктө иштеп, өзгөрүүлөрдү байланышка чыкканда Supabase менен шайкештештирет. Бир аккаунтка ар башка телефон жана компьютерден кирүүгө болот.

## Supabase жана GitHub Pages орнотуу

1. Supabase'те долбоор түзүңүз.
2. SQL Editor'ге [supabase/setup.sql](./supabase/setup.sql) файлынын мазмунун толугу менен көчүрүп, бир жолу иштетиңиз. Бул ар бир аккаунттун маалыматын анын Supabase колдонуучусуна гана ачкан RLS саясаттарын жана жеке сүрөт/видео сактагычын түзөт.
3. Supabase'тин **Project URL** жана **anon/public (publishable) key** маанилерин [web/config.js](./web/config.js) ичиндеги `url` жана `anonKey` талааларына жазыңыз. `service_role` же `secret` key'ди бул файлга, GitHub'га же тиркемеге эч качан кошпоңуз. Public key клиентте көрүнөт; маалыматтын коопсуздугун RLS саясаттары камсыз кылат.
4. Supabase **Authentication → URL Configuration** бөлүмүндө Site URL жана Redirect URLs катары `https://samat07.github.io/akyl/` дарегин уруксатка кошуңуз. Email каттоону күйгүзүңүз. Email ырастоо/сырсөз калыбына келтирүү каттары иштеши үчүн ишенимдүү SMTP кызматын конфигурациялаңыз.
5. `web/` папкасынын мазмунун GitHub Pages жарыялаган папкага жайгаштырып, браузерден сайтты ачыңыз. `config.js` өзгөрсө, жаңы Android AAB түзүп кайра жарыялоо керек.

Каттоо жана жаңы түзмөктөн биринчи кирүү үчүн интернет керек. Андан кийин түзмөктө сакталган маалымат офлайн өзгөртүлөт жана интернет чыкканда шайкештешет. Supabase'теги акысыз план квотага жана шарттарга баш иет; ири көлөмдөгү сүрөт/видео үчүн төлөм талап кылынышы мүмкүн.

## Android колдонмосу

Android Studio долбоору [android/](./android/) ичинде. Supabase туура конфигурацияланып, web файлдары даяр болгондон кийин Android Studio менен ошол папканы ачып, signed Android App Bundle (`.aab`) түзүңүз. Кадамдар үчүн [android/README.md](./android/README.md) караңыз. Бул репозиторий Play Console'го өзү жүктөбөйт; Play Console аккаунту, signing key, privacy policy жана колдонмо барагы өзүнчө талап кылынат.

## Эсеп функциялары

- Кой, козу, эчки, улак жана жылкыны адам боюнча эсептөө; уйдун жеке анкетасы жана сүрөттөрү.
- Өлгөн же чарбадан чыккан малдын саны, датасы, сүрөтү/видеосу жана окуялар тарыхы.
- Ар бир малдын багуу тарифин сом/баш/күн менен коюу жана топтолгон чыгымды эсептөө.
- Email + сырсөз менен жеке аккаунт; Supabase Auth аркылуу сырсөздү email менен калыбына келтирүү.
- Бир аккаунттун маалыматтарын интернет келгенде ар башка түзмөктөр арасында шайкештештирүү.

## Эски жеке сервер

`server.py` жана `data/` мурунку жеке Python серверинин файлдары; жаңы Supabase/GitHub Pages чыгарылышы аларды колдонбойт. Мурдагы `accounts.json` ичиндеги сырсөз хэштерин Supabase аккаунттарына өткөрүү мүмкүн эмес. Колдонуучулар жаңы email аккаунтун түзүп, эски мал маалыматтарын кол менен кайра киргизиши керек. Мурунку `data/` папкасын өчүрбөңүз; ал эски жазууларды сактайт.
